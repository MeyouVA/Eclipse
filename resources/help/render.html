Rendering and preview

The Camera view

  • Normal View draws the frame as you work on it, quickly: Edit > Preferences > Render can leave out of it effects, cutters and masks, gradients and textures, pencil textures and changing line thickness, scale pictures to the nearest pixel, and turn off its smoothing of edges. Renders always have all of it.
  • Render View (View menu, or the mode box at the foot of the view) shows the frame as it will be rendered. Each frame it renders is kept (Preferences: Render View Image Cache), so going back to it, or playing, does not render it again.
  • Auto Render: the Render View renders the frame again after each change. Off, it keeps what it rendered, marked out of date, until View > Render Current Frame.
  • Preview Resolution (beside the mode box in the Render View) renders at a half, a quarter or an eighth of the size, quicker. Progressive Render Preview shows a rough picture at once and the full frame a moment later.
  • Time limits (Preferences: Effect Render Timeout, Render Timeout): past them the Normal View leaves out the effects, then the layers, still to be drawn, and says so at the foot of the view. View > Disable View Timeout draws everything for now.

Writing frames

  • Formats: PNG, Targa (TGA), TIFF, Photoshop (PSD), OpenEXR (linear light, half float), SGI, DPX (10-bit), JPEG and BMP. Those marked with transparency keep the clear parts clear.
  • Each layer apart: a Photoshop file can hold every layer of drawings in the frame as a layer of its own, as well as the frame as a whole (the Export Images box, or the Layers column of Scene > Write Outputs).
  • Write outputs (Scene > Write Outputs) are renders kept with the scene; File > Export > Render Write Nodes (Ctrl+Shift+Y) makes all of them that are on, asking first when frames are already there.
  • Scene > Render > Auto Render Write: each frame the Render View renders in full is also written by the write outputs of images that are on.
  • Number of Rendering Threads (Preferences > Render): how many frames are rendered at once for exports, write outputs, movies and the Preview Manager; 0 uses all of the computer's cores.

Smooth edges

  • Layer Properties > Drawing > Antialiasing: Low draws hard edges, Very High works the edges out at twice the size. The Exponent makes the soft edge harder (above 1) or softer (below 1). Pictures: Nearest keeps each pixel of the layer's pictures square when they are scaled.
  • New drawing layers start with the quality and exponent set in Preferences > Render.
