Latest News

What is new in Eclipse 0.2. Help > Check for Updates looks for a newer version; once it has found one, this shows what that one brings.

Storyboards and editing programs

  • A storyboard in the scene: shots, panels, captions, sequences and acts (Window > Storyboard), printed to PDF through profiles.
  • Animatics brought in from Final Cut Pro XML, EDLs and OpenTimelineIO, and the storyboard written back out to them.

The scene database and batch work

  • Scenes kept in a shared folder with versions and rights to modify them (File > Database).
  • Batch Rendering, and programs beside Eclipse: eclipse-batch, eclipse-convert, eclipse-info, the Configuration Editor and the Service Launcher.

Help

  • Help on what is under the pointer (F1) and What's This (Shift+F1); a search through every page; a page of every command and of every preference.
  • Check for Updates, Report an Issue, and usage statistics kept on this computer only if you want them.
