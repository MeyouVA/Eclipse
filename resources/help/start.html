Getting started

Eclipse is a program for drawing and animating in two dimensions. A scene has layers, each layer has frames, and a frame of a drawing layer shows one of that layer's drawings.

A first animation

  1. Choose File > New, give the scene a size, a frame rate and a length.
  2. Pick the Brush in the Tools toolbar and draw in the Camera view.
  3. Click another frame in the Timeline and draw again: a new drawing is made there. The onion skin shows the drawings before and after in colour.
  4. Press Play in the Timeline's bar to see it move.
  5. File > Save keeps the scene in one .ecl file. File > Export makes pictures, a movie or a GIF.

The window

  • The Camera view in the middle is where you draw. The outline is the camera frame: what is rendered.
  • Tool Properties shows the settings of the tool in hand.
  • The Colour view holds the palettes and their colours.
  • The Timeline shows layers down the side and frames across.
  • Every other view is in the Windows menu. A view can be dragged to another place, floated, or closed; Windows > Restore Default Workspace puts everything back.
  • The view clicked in last has a red outline.

Getting about the Camera view

  • Hold Space and drag, or use the middle button, to slide the view. The wheel zooms.
  • View has Zoom, Rotate View, Mirror View and the Reset commands.
  • Edit > Undo takes back any step; nothing in Eclipse is done for good until you save.
