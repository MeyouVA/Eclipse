Effects and the node graph

Effects on a layer

The Effects panel lists what is done to the current layer's picture, in order: tick one to switch it on or off, pick it to change it. Their amounts can be animated - each has a row in the Timeline. The Node Library lists them all by kind.

  • Blurs: Blur, Directional Blur, Radial Blur, Variable Blur (as much as a matte layer is light), Motion Blur (a fading trail of the frames before) and Focus (depth of field: the further a layer stands from the depth in focus, the more blurred).
  • Colour: Tint, Colour-Scale, Hue-Saturation, Brightness-Contrast, Colour Curves (drag the curve, for all three colours or one), Negate, Black & White, Gradient, Tone and Highlight (shade and light where a matte lies), Channel Selector.
  • Light and shape: Glow, Shadow, Bloom, Grain, Median, Pixelate, Ripple, Turbulence.
  • Mattes: Cutter, Matte Generator, Matte Resize, Matte Blur, Matte Composite, Crop, Remove Transparency, Transparency.
  • Moving and output: Apply Peg Transformation (moved as another layer moves), Scale Output (made at a fraction of the resolution), Field Chart (a 12-field chart over the picture).
  • Particles: the layer's drawing thrown out again and again - sparks, rain, smoke.
  • Script: JavaScript run on the picture each frame - image.blur(4), image.tint("#ff8000", 0.5), image.pixel(x, y), image.setPixel(x, y, "#rrggbb") and more, with frame and amount.
  • External: a program run on the picture each frame: it reads {in} and writes {out} (PNG files); {frame} is the frame.

Edit > Preferences > Render can switch Blur and Focus off everywhere, for speed while working.

The node graph

The Node View shows the layers as nodes. Wire the Graph by Hand (in its menu) turns that into a graph of nodes and cables you change yourself; the frame is then made as the graph says, in the Render view, exports and printing.

  • Right-click to add nodes: Composite, effects, Group, Note, Display. Drag from an output to an input to cable them.
  • Effects with a second input take their matte there - Cutter, Tone, Variable Blur, Blending (laid over it by a blend mode) and Glue (joined to it, the gap between filled smoothly).
  • The ends of layer, peg and group nodes are their parenting: cable a layer to a peg to hang it there.
  • A layer node can give only some of its art layers - Line Art, Colour Art, Underlay, Overlay (Art Layers, in its menu).
  • Double-click an effect node to set it; its amount can be keyframed.
  • Ctrl+click nodes, then Group: the cables across the group's edge become its inputs and outputs.
  • Stack the Layers Again goes back to the layers drawn in order.

Scripts

The Script Editor (Windows menu) keeps JavaScript scripts that change the scene - layers, keyframes, drawings, palettes, effects; the Python Console does the same in Python, if Python is installed. Each run is one step to undo.
